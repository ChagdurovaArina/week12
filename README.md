# Week 12 데이터 분석

## 데이터

- 파일: scores_2026.csv
- 원본 데이터: 114행, 5열
- 정제 후 데이터: 100행, 5열

## 열 설명

- 학번: 학생 번호
- 이름: 학생 이름
- 반: 반 정보
- 과목: 과목명
- 점수: 시험 점수 (0~100점)

## 데이터 정제 방법

1. 점수가 비어 있는 행 6개를 삭제했다. 점수가 없으면 평균을 정확하게 계산할 수 없기 때문이다.
2. 모든 열의 값이 완전히 같은 중복 행 4개를 삭제했다.
3. 반과 과목의 앞뒤 공백을 제거했다.
4. 점수가 0~100 범위 밖인 행 4개를 삭제했다.

## 분석 결과

- 1반 전체 평균: 78.24점
- 2반 전체 평균: 71.44점
- 과목별 평균: 프로그래밍, 영어, 수학 모두 2반이 더 높았다.

## 결론

전체 평균에서는 1반이 높았지만, 과목별 평균에서는 2반이 모두 높았다. 이는 과목별 학생 수의 차이와 관련이 있다.
